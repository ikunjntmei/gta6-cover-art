Vice City Cover Studio: an offline web app that turns your photos and a caption into GTA 6-style poster cover art. Pick one of five multi-panel layouts (full bleed, duo split, hero + two, four-panel grid, three-strip), drop in up to four of your own photos, crop each panel by dragging or with the sliders, choose one of five Vice City colour grades (sunset, neon nights, palm gold, noir, lagoon), letter the title in big condensed poster type with a neon script subtitle, and export PNG covers in all three post sizes — 1080×1080, 1080×1350 and 1920×1080 — in one click. Everything runs in the browser with no network requests and no uploads; two sample photos are built in so you can make a cover in seconds.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Add your photos (or use the samples), pick a layout and a grade, type a title, and press “Export all 3 sizes”.
